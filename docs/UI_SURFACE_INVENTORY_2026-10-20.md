# UI 界面迁移清单（2026-10-20）

本清单对应当前源码，范围为整个工作台和全部 App 内二级界面；系统 SAF 文件选择器、输入法及系统文本操作工具条仍由 Android 管理。

| 界面 | 实际接入 | 回归重点 |
| --- | --- | --- |
| 主页面/标签/路径/编辑工具栏/状态 | 灰蓝与浅色令牌、Lucide、类型徽标、终端入口、图标编辑操作 | 窗口宽度、文件与焦点保持 |
| 手机资源管理器 | 左侧全高抽屉、关闭按钮、授权类型说明、引导线与选中态 | 根目录收起、深层路径、48dp操作 |
| 主菜单/编辑菜单/项目菜单 | WorkbenchMenu，原 MenuItem/命令回调保留，图标/快捷键/分组/危险状态 | 命令可达、窄窗口、Esc |
| 文件长按/右键、新建/重命名 | WorkbenchStyle/统一表单，错误保留输入 | 保存失败、名字校验、新建目标 |
| 移动文件/目录 | 当前路径、返回上一级、分层目录选择、禁用无效目标 | 不移动到自身或子目录、失败不丢草稿 |
| 删除/重新载入/切换工作区/退出 | 共用确认表面及危险按钮颜色 | 原有确认与保存保护 |
| 切换项目/最近目录/恢复草稿 | 共用选择列表和说明 | SAF身份、旧数据与版本保护 |
| 文件查找替换/项目搜索/跳转行 | 共用输入与结果样式、紧凑操作分组 | 后台取消、文档版本、结果定位 |
| 设置中心 | 手机分类进入/平板分栏，搜索、草稿、取消、应用、恢复 | 应用失败留草稿、关闭后不因换主题重开 |
| 终端会话/操作/配色/尺寸 | 共用菜单与选择状态，独立配色入口 | 单一PTY、会话不重建、控制键与键盘 |
| 补全/参数/片段 | 同类表面和本地图标，48dp控件，原光标锚点 | 组合输入、定位、候选失效保护 |
| 错误详情/快捷键/帮助/权限/许可证 | 共用滚动详情与按钮，真实边界说明 | 信息可复制、错误可定位、原许可保留 |

主机验证与浏览器设计预览不代替实机视觉/输入验收。完整结果见 [UI_COMPLETE_2026-10-20.md](UI_COMPLETE_2026-10-20.md)。
