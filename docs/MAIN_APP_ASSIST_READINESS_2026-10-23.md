# 主工作台补全与参数提示的布局等待修复

2026-10-23；基线 `5c5809be0cead80c7fd9550e981b297af9d65dc4`，继续I2主程序操作链。沿用同一个MainActivity、共享Sora编辑器、保存/文件/设置和真实运行入口，不新增实验界面或第二个终端。

## 原因与修复

主程序此前会在Sora异步重排时立即执行候选/参数查询；光标锚点暂时不可用，就把真实结果当成“空间不足”丢弃。关闭自动补全/自动参数提示时，Ctrl+Space和Ctrl+Shift+Space没有后续重试，用户必须再次操作。内部工具中已有等待策略，主程序接入时遗漏了这部分。

现在主工作台在查询前以及工作线程结果回到UI时检查布局。尚未就绪时保留请求模式和主动触发意图，最多等待2秒，每32ms只读取轻量视口戳，不复制整份源码、强制绘制、修改选区或请求IME焦点。就绪后使用现有真实词法/片段/内置参数实现继续处理。自动刷新不会覆盖正在等待的主动请求，新的快捷键请求取代旧请求。

等待绑定编辑器/Port、当前文件与修订、选区和交互版本；编辑/替换、切文件、组合输入、失焦、弹出工具窗口及生命周期变化按既有取消路径失效。Esc也可取消等待；超时只对主动请求提示“仍在排版”，可以重新请求。普通候选和参数提示的原定位、键盘路由、来源说明及保护条件保留。
