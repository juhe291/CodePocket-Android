## 实际功能

- 左侧增加真实源代码管理入口，和树/搜索共用手机抽屉、平板侧栏及固定活动栏。显示分支、已暂存/未暂存/未跟踪文件、真实差异、暂存/取消暂存、提交及历史。无项目给打开入口，已有项目但非仓库给初始化入口，不假报干净。
- 固定纯 Python Dulwich 1.2.20 和 urllib3 2.8.0，由独立、非导出的 `:git` 服务处理自有私有快照，不要求设备预装 Git。姓名、邮箱和提交说明可填写；提交草稿按工作区保留，取消、重建和失败不丢消息。历史预览可继续查看完整提交消息，差异/错误沿用全文选择、复制和关闭的阅读浮层。
- 内部目录和真实 SAF 提供方都读取新鲜二进制内容，原编辑/运行镜像跳过根 `.git`。暂存当前未保存文件先走原保存和版本冲突保护；其他恢复草稿可选择打开保存或明确仅暂存磁盘版本。迟到结果不能跨工作区发布，也不能关闭设置草稿。
- 写入只批准本地 Git 元数据，工作正文不写入本批 Git 事务。发布有持久 before/after 备份、内容身份和写后校验；已知自身写入可条件恢复，未知部分写入保留备份并提供恢复记录与 ZIP 导出。内部目录持有标准索引/HEAD/config/相关分支锁，重启仅清理日志可证明属于自身的锁。SAF 不承诺跨文件原子性，未知版本绝不静默覆盖。
- 禁用外部钩子、全局配置、自动维护/GC和签名程序；不支持的工作树/共享对象布局、过滤器/LFS、合并/变基进行中状态有明确错误。读取和差异有界，历史简要预览与完整消息分开。Git 组件原始许可加入原设置许可入口。
