# CodePocket 工作台视觉重构：第一批（2026-10-23）

## 当前优先级与边界

用户最新指令优先：UI 视觉、结构和操作层级优先。原需求保留，未实现功能先不接入；后续非阻塞问题先记录。本批不修改文件系统、运行引擎、PTY 解析和输入底层。上一轮 Jedi 15 项主机测试的 WIP 已完整移至 `verification/python-semantic-probe-2026-10-23/parked/`，不进入生产 Python 和默认测试发现，也没有新增 pip 依赖。

## 原因与新层级

旧布局将文件树放在编辑器/终端组合旁，文件树因而贯穿终端高度；窄窗口还没有 Activity Bar。现在用现有原生 Views 增量调整：

```
Root
├─ MainToolbar：宽屏六组菜单 / 窄屏分类菜单，项目标题，终端，运行
└─ ContentHost
   ├─ ActivityBar：文件、搜索、运行；底部设置，溢出区域可滚动
   └─ MainWorkspace
      ├─ SplitHost（始终纵向）
      │  ├─ TopWorkspace
      │  │  ├─ Primary Side Bar + Resize Handle（按窗口显示）
      │  │  ├─ EditorRegion：标签/编辑操作、路径、Sora
      │  │  └─ AuxiliarySlot（隐藏，未接入新功能）
      │  ├─ Panel Resize Handle
      │  └─ Bottom Panel：现有真实终端/问题/输出
      ├─ 编程符号栏（按原输入状态显示）
      └─ StatusBar
```

终端横跨上方文件树与编辑器总宽度，保持在 Activity Bar 右侧；最大化时隐藏整个上方工作区，恢复不重建编辑器/文件树。旧侧停靠偏好继续保存在配置中，新工作台明确使用底部停靠。

## 视觉与操作

- 中性深灰、少量灰蓝强调；本地 Lucide 图标，无发光/渐变。导航选中细线，设置固定底部。
- 桌面单行文件/编辑/视图/运行/终端/帮助；手机更多菜单先选分类，再选现有命令，保留既有执行校验。
- 保存/撤销/重做/查找移入标签栏右侧，窄编辑区仅保留保存，统一通过顶部编辑分类访问其他动作，其他操作仍在编辑菜单。移除常驻底部编辑操作条。
- 按最新反馈去掉突兀蓝色底栏、重复更多和常驻文件说明；添加标题细分隔线、目录选中短色条。状态栏在右侧工作区底部，实际错误/保存信息及行列/语言保持可访问。
- 手机文件抽屉避开导航栏，选中文件沿用已有保存/切换保护；固定文件树仍记忆宽度、展开和选择状态。
- 终端不可启动的 IDE 状态提示改为扁平呈现，弱化大卡片；不伪造程序输出。

## 四种窗口与证据

实际窗口宽度至少600dp且工作区高度至少480dp时可固定文件树；窄或矮窗口使用临时抽屉。完整菜单从1000dp启用且避让大字体。平板启动面板原600×480dp/35%规则保留，手机默认收起。

本批 `WorkbenchStructureIntegrationTest` 用实际 MainActivity/Sora 原生绘制：1280×800深色平板横屏、800×1200浅色平板竖屏、840×411手机横屏、411×891深/浅手机竖屏。截图为主机 Robolectric Native Graphics，不是设备截图或帧率证据。主机没有Android Shell，截图中的失败提示是实际主机边界，不能算设备终端回归失败或运行通过。

截图位于 `docs/workbench-redesign-preview/`（构建完成后同步），完整原始记录位于 `verification/workbench-redesign-2026-10-23/`。
