# P1 第三批：可调运行面板（2026-10-17）

在现有 Kotlin/View 编辑器上加入运行面板拖动、最大化/恢复和独立尺寸记忆。没有重建项目或替换编辑器；此前设置/查找、词法列表及 P0 文件与运行实现保留。用户要求所有功能完成后统一实机，本批只做主机回归和 APK 检查。

## 已实现与操作入口

| 功能 | 实际行为 |
| --- | --- |
| 真实工作区尺寸 | 以扣除文件树之后的 splitHost 实测宽高选择停靠；宽度达到 600 dp 时放右侧，其余放底部。展开/收起文件树或窗口改变会重新计算，同一 Activity 内保留原编辑器/输入/输出视图。 |
| 拖动尺寸 | 运行面板与代码之间有 24 dp 拖动条；向上/左拖增大，向下/右拖减小。按原生 MotionEvent 指针身份跟踪，结束/取消/窗口变化会清理手势。MOVE 直接更新尺寸，不逐帧写偏好、读文件或等待尺寸动画。 |
| 菜单与无障碍 | 面板 ↕/↔ 按钮或点击拖动条打开“减小/增大/默认尺寸”菜单；还有清空当前文件 stdin。拖动条获得焦点后支持相应方向键和 +/-；提供可访问范围、增减及设置进度接口，实际读屏和硬件行为待测。 |
| 最大化与恢复 | □ 最大化运行面板，▣ 恢复；最大化占满工作区域，仍保留顶部操作和文件树入口。× 收起，“结果”重新打开。窗口不足以同时显示时，明确打开结果会使用单面板模式，仍能恢复代码。 |
| 尺寸记忆 | 分别记住底部高度比例、侧边宽度比例和最大化状态，保留旧 panelVisible 偏好；关闭面板清除最大化状态。IME/窗口临时压缩只限制实际尺寸，不改写记忆的比例。配置缺失、损坏、非有限值和越界均回退/约束。 |
| IME 与 stdin | 默认编辑代码时仍按设置收起面板；聚焦 stdin 保持面板可用。窄矮窗口优先保留正在编辑的 stdin，紧凑时隐藏额外标题/标签，清空输入仍可从面板菜单完成。最大化代码结果时不主动弹软键盘。 |
| 视口与焦点 | 编辑区隐藏后捕获会话继续保留此前代码选区与滚动，stdin 文本及选区继续更新。恢复视口校验文件身份、编辑版本和选区，组合输入时跳过；首次尚未测量时不提前隐藏 stdin，避免恢复焦点失败。 |
| 输出与跳转 | 输出/错误/运行信息标签改为原生横向滚动，侧边面板窄时可继续访问；首次无结果也初始化标签与说明。查找、跳转行、打开文件和错误定位可退出最大化并显示源码，错误定位调用明确返回 Unit。 |

普通底部布局给运行区至少 208 dp、编辑区至少 128 dp；侧边布局分别为 200/240 dp，另计拖动条。stdin 的 IME 紧凑布局有单独下限。当尺寸不足时保留代码或正在输入的 stdin；“结果”提供明确切换入口。实际超小窗口、浮动输入法和大字体显示仍需设备检验。

面板尺寸/显隐变化不调用 setText 重建代码、stdin 或输出缓冲区；首次标签初始化仍走已有输出渲染。菜单清空当前 stdin 是明确的用户操作，复用原有独立输入更新路径。布局按钮仅在符号实际改变时更新文字，避免每次 global layout 都再次请求布局。最大化/恢复沿用短淡入和系统/App 动画策略，拖动不使用追赶动画；完整展开/收起过渡、平滑光标与帧率指标仍未完成/测量。
