# I3：主Sora光标动画与编辑器配色一致性（2026-10-23）

本批将此前约定的约60ms键入/退格、约80ms近距离移动与柔和闪烁接到实际主编辑器。继续使用Sora的Content、光标、布局、IME和原主工作台；文件、保存、补全算法、Python/C++及单一真实PTY保持。I3进入已实现光标动画、继续整体界面/窗口核对的状态，不代表I3/I4及原P2/P3全部完成。

## 修改与行为

- 新增 `editor-sora/.../SoraCaretMotion.java`，通过精确0.23.7公开CursorAnimator接口提供一个可取消的视觉过渡，替代原组件固定120ms、间隔不足100ms会过滤连续操作的默认动画。新输入立即接管当前视觉位置，无排队、无输入限速。
- 修改 `SoraInputEditor.java`、`WorkbenchEditor.java`：接入现有设置和生命周期，切文档、显示候选/参数、暂停/失焦/离开窗口等立即对齐或停止；当前缓冲区、真实插入点、文字和实际选区立即更新。当前行背景使用组件的真实目的行，不平移代码或当前行区域。
- 约60ms用于普通键入/退格，约80ms用于短距离点选/方向键移动；组合输入、选区/拖动、批量文本、撤销、远跳、滚动、尺寸/字体/行号区变化均直接定位。组件异步重排期间取消视觉过渡，最终坐标以其发布的真实布局为准。
- 停止操作约600ms后进入1秒周期的柔和明暗变化，最低约15%不透明度。移动/闪烁可分别关闭；已有App动画总开关、系统减少动画及省电观察真实生效。名义时长仍遵守Android系统时长缩放，不声明设备延迟/FPS。
- 淡化只在onDraw内临时调整当前编辑器独有配色的插入光标颜色，并在finally恢复；这两次临时更新不触发Sora文本RenderNode缓存失效。实际位图测试确认变化限于光标附近，文字/文档修订不变，且不产生ColorSchemeUpdateEvent。未修改成熟终端或编辑器解析/输入底层。
- 修复语法主题稍后加载会覆盖主工作台光标色的问题；保留主界面配置的光标颜色。
- 修改 `SoraSyntaxController.java`：目视发现组件原备用VS2019主题使用青色行号/分隔线、较亮行背景，和加载后的主题不一致。现在备用、已加载及语法失败回退统一柔和灰蓝的行号、引导线、行背景和选择手柄。深浅主题均验证，语法Token配色继续使用既有实现。
- 新增主程序 `MainCaretMotionIntegrationTest.kt` 9项、共享 `SoraCaretMotionTest.java` 17项；不扩展独立实验页，不新增第二个用户App。Settings JSON、Gradle、Manifest和Actions不变。
