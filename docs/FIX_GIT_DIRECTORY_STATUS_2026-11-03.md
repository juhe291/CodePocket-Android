## 根因与当前修改

固定Dulwich1.2.20在读取索引子路径old/child时只处理FileNotFoundError。父目录old已变成普通文件时，Linux返回NotADirectoryError（ENOTDIR），原生产状态被统一报告为repository错误；Windows通常返回ENOENT，因此旧本机检查没暴露。

新回归在真实自有仓库完成目录→文件替换，仅将该不可达索引子路径的lstat错误设为POSIX ENOTDIR，原生产状态确实失败。21项基线20通过/1失败，包含新测试2项；原索引/工作树只读、真实暂存/提交、标准Git对象和未跟踪文件断言保留，另要求无真实遮挡父文件的异常不能变成干净状态。

生产仅在porcelain.status抛NotADirectoryError时走窄兼容路径：逐项确认索引子路径有真实普通文件祖先，只对未暂存读取忽略这些不可达子路径并明确列为删除；完整索引用于已暂存/未跟踪比较，沿用正式blob规范化，不写索引、不改配置、不捕获其余存储错误。21项修复后全部通过。
