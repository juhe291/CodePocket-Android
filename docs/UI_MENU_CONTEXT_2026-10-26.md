# 菜单上下文与返回层级（2026-10-26）

在c596ce2基础上继续UI视觉与操作层级。当前主菜单和终端菜单进入分类后没有标题/返回入口，终端图标仍部分依赖文案推断。本批使用现有Views和命令模型补齐上下文，不添加编辑/运行功能。

## 改动

- WorkbenchMenu增加可选固定分类标题，正文独立滚动；从分类进入的子菜单提供48dp返回按钮，方向左键返回，Esc保持关闭。直接从平板菜单栏打开分类时显示标题，不显示多余的父级按钮。
- 极窄/极矮的可用区域继续优先保留命令列表；普通手机、平板和大字体的标题/返回有主机回归。系统Back仍由平台管理，本批没有改成拦截系统返回。
- 终端四类采用稳定身份和明确的线性图标；会话结束单独危险分组，清空、键盘、复制/粘贴、重启、布局、配色等按功能指定图标，继续调用原执行校验。
- “布局与输入→面板尺寸”可以返回实际父分类，再返回终端分类；打开菜单和返回不改变面板尺寸或选中会话模型。
- 返回处理检查窗口仍在显示、锚点仍挂接；终端回调保留会话身份校验。已关闭窗口的旧按钮回调不重开父菜单。
- 原无标题选择器保持原ScrollView结构；有分类标题时使用标准纵向布局与ScrollView，不重写编辑器、文件系统或PTY。
