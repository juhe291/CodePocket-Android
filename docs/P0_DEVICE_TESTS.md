## 最终验收追加：P1 设置与补全（统一后置，尚未执行）

- 重启后保持独立 UI/语法主题、字号、Tab/换行和 3 项补全按键配置；旧 version 1 配置升级不丢工作区与 stdin。
- Ctrl+Space、触屏“补全”含 IME 紧凑栏、第二候选/Enter/Tab/Esc、Ctrl+S/F5 与原生鼠标滚动/选择联合回归。
- Enter 默认换行，开启接受后需方向键明确选中；中文组合期间不吞确认，软键盘标志事件放行；焦点在 stdin 不应修改代码。
- 词中补全不重复后缀，接受后原生撤销/重做、保存和重启恢复正确；改变代码/光标/文件后不能接受旧结果。
- 长行、软换行、emoji、CRLF、滚动、屏幕边缘、分屏/浮动窗口/平板与 API 24–28/29+ 的候选定位；输入法不遮挡弹窗或光标，空间不足正确收起。
- 自动补全关闭和 45000 字符以上降级，成员位置不伪装语义；系统减少动画/App 关闭/省电时无淡入，输入不等待动画。实际帧率另采集，不以编译通过替代。

## 最终验收追加：P1 可调运行面板（统一后置，未执行）

- 手机、平板、卓易通，横竖/分屏/浮动窗口、大字体；展开文件树后按剩余工作宽度停靠，208/128 dp 底部与 200/240 dp 侧边下限不会挤掉当前输入。
- 拖动条上下/左右调尺寸，鼠标拖动/光标、获得焦点后的方向键与 +/-、尺寸菜单、无障碍增减/设值；按下后多指/取消/切后台/窗口变化不残留手势。
- 两方向分别记忆比例，键盘与临时小窗只约束实际尺寸；恢复窗口后还原用户比例；重启和切主题保持尺寸/开关/最大化意图。
- □/▣/×/结果反复操作，不改写代码/stdin/输出；代码/stdin 选区与横纵滚动保留；最大化状态重启时聚焦的 stdin 可恢复，不强制弹出软键盘。
- IME 下编辑代码按设置收面板，编辑 stdin 不被挤掉；紧凑模式清空当前输入仍可用；输出/错误/信息可访问，错误定位/查找/跳行/切文件能显示源码。
- 运行/停止/超时/保存/SAF/草稿与补全同时回归；拖动不触发源码重写或逐帧偏好写入。帧率和输入延迟需实测，不能以构建成功代替。
