## 已写入的生产代码

1. 固定工具与运行器：锁定 Clang/LLD 21.1.8-3，复用当前 LLVM 私有闭包；新增四个 CRT/compiler-rt/libunwind 链接输入和三份上游许可全文。准备脚本默认离线，新增输入沿用原显式 fetch。NDK 编译安装包原生运行器，Gradle 将其暂存为 `libcodepocket_cpp_runner.so`；不会 execve 私有可写目录里的生成程序。
2. 受控命令进程：独立 `codepocket_execute` JNI 与 Kotlin 封装，命令数组/UTF-8、双路输出、代次句柄、CPU/地址空间/文件大小限制、退出码和信号区分、退出后继续读取输出。观察退出时保留未回收 PID，释放时才终止自有进程组并回收，避免旧句柄误用已复用 PID。此底层已交叉编译，JNI 内核行为尚未在 Android 执行验证。
3. 项目构建：每次运行新建独立源码副本，读取当前正文、实时项目文件和有效恢复草稿；源码与构建目录分开，取消/失败清理只涉及自有副本。固定 C++17 参数，支持当前文件与全部项目编译单元两种范围；不运行项目脚本或配置。双路输出共用预算，构建总时间限制，真实编译错误可保留文件、行号和源码摘要。
4. 共享程序检查：执行前检查真实 ELF64/arm64、16KiB 加载段、不可执行栈、文本重定位及已定义 `main`。安装包运行器加载只读程序并调用真实入口，正常返回会执行全局析构。

上述组件尚未接入独立执行服务和主工作台。当前 F5 仍走原路径，没有把半成品作为新运行模式展示给用户。
