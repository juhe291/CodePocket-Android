# CodePocket 交互架构重构方案

> 2026-10-17 接续说明：本文保留原设计/阶段记录。中断后的实际接线、修复、测试及尚未完成项见 [UI 接续报告](UI_RESUME_2026-10-17.md)；本批没有实机截图或帧率证据，SGR显示不等于流式交互终端。

2026-10-17，基于用户反馈和 VS Code 交互范式设计。

## 一、当前问题

### 严重问题
1. **菜单过载**：文件/编辑菜单需要滚动，严重遮挡代码
2. **高频操作埋没**：撤销/重做/查找藏在菜单深处
3. **上下文混乱**：布局控制、文件操作、数据操作混在同一菜单
4. **触屏体验差**：过度依赖键盘快捷键
5. **工作流不清晰**：文件→编辑→运行→结果流程不够直接

### 根本原因
- 为了缩减工具栏，把所有操作堆进一个巨大的菜单
- 没有按用户实际工作流程组织功能
- 缺少 VS Code 风格的文件树和侧边栏
- 终端面板定位模糊（预设输入/实时输入/输出混在一起）

## 二、新信息架构

### 核心工作流
```
打开项目 → 选择文件 → 编辑代码 → 运行程序 → 查看结果 → 继续编辑
   ↓          ↓          ↓          ↓          ↓          ↓
Explorer   文件树      编辑器     Run按钮    终端面板    编辑器
```

### 功能分层

**第一层 - 主工具栏**（始终可见）：
- Explorer 按钮
- 项目名称
- 搜索按钮
- Run/Stop 按钮
- 更多菜单（全局设置）

**第二层 - 上下文工具栏**（根据状态显示）：
- Explorer 侧边栏：文件树 + 文件操作按钮
- 编辑器工具栏：撤销/重做/查找（宽屏显示）
- 终端工具栏：清空/最大化/关闭

**第三层 - 弹出式交互**：
- 长按菜单：文件树右键、代码选区操作
- 底部栏：编程符号快捷键（软键盘弹出时）
- 对话框：重命名、查找替换、设置

## 四、模块职责划分

### 1. MainToolbar（主工具栏）
**职责**：全局导航和核心操作
- Explorer 按钮：切换侧边栏
- 项目名称：显示当前项目，点击切换
- 搜索按钮：打开搜索对话框
- Run/Stop：运行/停止当前文件
- 更多菜单：设置、帮助、关于

**移除**：所有文件、编辑、面板操作

### 2. ExplorerSidebar（资源管理器侧边栏）
**职责**：文件和项目管理
- 文件树：展开/折叠，点击打开
- 工具栏：新建文件、新建文件夹
- 长按菜单：重命名、删除、移动
- 底部：打开工作区、切换项目

**新增**：完整的文件树交互

### 3. EditorToolbar（编辑器工具栏）
**职责**：代码编辑辅助
- 撤销/重做（始终显示）
- 查找/替换（宽屏显示）
- 格式化（条件显示）

**移除**：插入 Tab、括号等低频操作

### 4. SymbolBar（符号快捷栏）
**职责**：触屏编程辅助
- 显示时机：软键盘弹出时
- 内容：Tab、{}、[]、()、;、:、=
- 位置：键盘上方

### 5. TerminalPanel（终端面板）
**职责**：运行输出和交互
- 工具栏：清空、最大化、关闭
- 标签页：stdout、stderr、info
- 输出区域：支持 ANSI 颜色
- 错误定位：点击跳转

**移除**：布局控制混在数据操作中

### 6. SettingsMenu（全局菜单）
**职责**：低频全局操作
- 设置
- 快捷键说明
- 帮助
- 关于

**移除**：所有编辑、文件、面板操作

## 五、交互优化

### 触屏体验
- 长按文件树项目：显示操作菜单
- 长按代码选区：复制/剪切/粘贴/注释
- 双指缩放：调整字体大小
- 滑动标签：切换文件
- 上下拖动分隔条：调整终端高度

### 键盘体验
- 保留所有快捷键
- Ctrl+B：切换 Explorer
- Ctrl+F：查找
- F5：运行
- Ctrl+Z/Y：撤销/重做

### 返回键行为
1. 关闭弹出菜单/对话框
2. 关闭侧边栏
3. 收起终端面板
4. 提示未保存并退出

### 软键盘适配
- 弹出时：显示符号栏，保持光标可见
- 收起时：隐藏符号栏，恢复编辑器高度

## 七、验收标准

**核心任务**：
1. 用户能否不看教程，直接完成创建文件？
2. 用户能否自然地在多个文件间切换？
3. 用户能否快速找到撤销/重做/查找？
4. 用户能否一键运行并查看结果？
5. 用户能否轻松关闭不需要的面板？

**禁止出现**：
- 需要滚动的超长菜单
- 高频操作藏在三级以上菜单
- 布局控制和数据操作混在一起
- 触屏操作需要多次点击才能完成的任务
