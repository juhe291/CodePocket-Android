# 文件树状态与标签一致（2026-10-26）

在6daadc5基础上继续当前UI范围。本批补齐用户要求中的文件树“未保存文件状态显示”，继续使用克制的文件类型色和固定位置小标记，不增加按钮或运行功能。

## 改动

- 当前文件键入后，文件树与标签同步出现未保存圆点；成功保存后清除，保存冲突/失败时保留。完整路径和“未保存”同时进入辅助说明及鼠标提示。
- 圆点直径6dp，文件名右侧固定留出16dp；只重绘标记，不改变文件名文字、不移动菜单目标。根目录和文件夹不显示文件未保存标记。
- MainActivity沿用已知的activePath/dirty状态更新现有ExplorerRow；普通输入不重建文件树、不重新遍历目录、不增加主线程草稿读取。抽屉重开和目录展开使用同一状态绑定。
- 不更改保存保护、草稿、文件事务、文档切换或运行底层。非当前恢复草稿的完整状态总览不作为本批新功能；切换文件仍沿用原保存保护。
- 可点击样稿在原“未保存标签”和“保存失败状态”中同步展示文件树标记，没有新增示例运行结果。
