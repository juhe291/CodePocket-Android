# P1-E1 工作台动画与稳定刷新（2026-10-19）

基线 `8011d7b`。用户确认上一轮终端可继续后，接续原 P1 动画/UI 计划；在现有 Kotlin / Android Views 上修改，没有重建工程或迁移生产编辑器。**本批是动画首个增量，P1 完整动画及 P2/P3 均未宣称完成。**

## 改动与原因

| 文件 | 原因与本批行为 |
| --- | --- |
| MainActivity.kt、ui/KeyedViews.kt | 旧文件树展开/收起和标签刷新都会 removeAllViews。改为按工作区相对路径保留已有行、标签与关闭按钮，只插入/移除变化项；普通刷新不分离存活行，顺序变化时保留原焦点。新行短时淡入，文件切换不再让整个标签栏反复淡入。 |
| ui/ExplorerRow.kt | 新增独立展开箭头、目录引导线、选中态和触摸反馈。箭头150ms旋转，新出现行120ms淡入；正文与点击区域立即处于最终位置。目录缩进同时受层级、96dp上限和窗口剩余空间约束，192dp窄栏与大字体下仍保留名称空间；完整路径用于辅助说明。整行至少48dp。 |
| ui/EditorTab.kt | 活动标签顶部2dp标记、单行省略文件名、独立48dp关闭按钮；脏状态更新复用原名称视图，避免丢实体键盘焦点。 |
| animation/Animations.kt、res/values/motion_ids.xml | 每个动画记录最终状态；取消/移除时结算可见性、透明度及偏移/旋转，清掉旧回调。快速关开不会被迟到回调再次隐藏；不再出现逻辑已关闭但残留可见的侧栏。窗口失焦、后台、界面重建、IME出现或应用关闭动画时取消子级过渡。 |
| CompletionPopup.kt、SignaturePopup.kt | 原每批候选/参数更新都将alpha重置为0.85，连续输入会重复淡入。现在仅初次打开做90ms淡入，窗口已显示时原位更新；关闭或关闭动画时恢复最终状态。原锚点/文档代次/光标校验和输入归属保持。 |
| CompletionModel.kt、SignatureHelp.kt | 清理 input() 帮助中遗留的“当前使用预填stdin”文案，改成真实终端输入、Enter提交。没有改变补全算法或 Python 执行机制。 |
| ui/IdeControls.kt、ui/IdeIcons.kt | 复用原生触摸反馈；在已有原创线形图标中补展开箭头，没有添加图标字体、网络资源或新许可依赖。不是完整Lucide替换。 |

本批不按帧动画布局参数，不平移/缩放代码正文和终端字符，不改真实PTY尺寸调度。终端键盘、前台桥、隔离Python服务、停止/超时、Wandbox、原生CodeEditor、Workspace/SAF/草稿、Gradle及GitHub Actions源码保持。
