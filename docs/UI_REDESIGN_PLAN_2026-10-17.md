## P1-A 手机竖屏结构

```text
┌──────────────────────────────────────┐
│ Explorer  项目或当前文件（单行）  ▶  ⋮ │ 单排主工具栏
├──────────────────────────────────────┤
│ main.cpp ×   helper.hpp ×   main.py × │ 横向标签；长文件名可查看完整路径
├──────────────────────────────────────┤
│  1  #include <iostream>              │
│  2  ...                             │ 主体优先给代码
│                                     │ 候选/参数只在需要时出现
├──────────────────────────────────────┤
│ 输出（预设输入模式）  测试输入  □  ×   │ 真实后端模式明确
│ 程序结束后的输出/问题/运行信息         │ 收起后不占正文空间
├──────────────────────────────────────┤
│ C++ · Ln/Col · Tab 4 · UTF-8 · 就绪  │ 简洁状态，后续批次完善交互
└──────────────────────────────────────┘
   Tab  {}  []  ()  ;  =  :  ← →       IME/代码焦点按设置出现
```

这是布局线框，不是 App 截图。首批使用原生 View/PopupMenu 等现成能力精简外壳，不迁移 Compose，不同时改写编辑内核。手机 Explorer 采用窄窗可用的侧面/全高入口；先保留真实文件树操作，后续替换渲染方式。

- 主栏只保留 Explorer、弹性单行项目/文件名、运行/停止、更多。长名字采用可解释的省略并可查看完整路径，避免换行或按钮溢出；不承诺任意长文本都完整塞进一排。
- 保存、新建、导入/导出等移入命令菜单和 Explorer，不为每个功能新增长期可见按钮。运行时原运行位置变停止，仍能立即操作。
- 不常驻快捷键说明；说明进入帮助/菜单。代码编程栏按焦点和设置显示，stdin 获得焦点时不能改源码；外接实体键盘不强制弹 IME。
- 预设 stdin 保留每文件存储契约，默认收纳到“测试输入”入口，用户选择时再展开/编辑；清空只影响当前文件。运行输出仍明确“预设输入，结束后展示”，不伪装终端等待输入。
- 标签、文件/焦点/选区/滚动/脏标记以及失败草稿保留；新布局只改变承载和入口，不重新解释 SAF URI、文件身份或保存策略。

## 统一视觉令牌与后续验证

以下初始方案已落实到外壳令牌；深色强调文字实际采用 #4DAAFC，控件强调色保留 #0078D4，以满足普通文字 ≥4.5:1 的静态检查。字体缩放、触控与完整主题仍待实机验证，不能称完整主题移植。

| 令牌 | 深色建议 | 浅色建议 |
| --- | --- | --- |
| 编辑器背景 | #1F1F1F | #FFFFFF |
| 工具栏/面板 | #181818 | #F8F8F8 |
| 主文字 | #CCCCCC | #1F1F1F |
| 辅助文字 | #9D9D9D | #616161 |
| 分隔线 | #2B2B2B | #E5E5E5 |
| 强调色 | #0078D4 | #005FB8 |
| 间距 | 4/8/12/16 dp | 相同 |
| 图标/线条/圆角 | 图标 18–20dp、1–1.5dp 线条；面板 0–4dp 圆角 | 相同 |
| 主栏/触控 | 主栏 48dp；触屏可操作目标优先至少 48dp | 相同 |

编辑器字号继续可配置，不硬编码到 UI 令牌；正文控件使用 sp 和 dp。紧凑视觉与触控区域分别设计，不能用透明触控扩展覆盖代码输入区；状态信息可以紧凑，但设置等触屏操作保留足尺寸菜单入口。[Android 触控目标建议](https://developer.android.com/guide/topics/ui/accessibility/apps#large-controls) 作为验收参照。

优先统一现有矢量资源与组件状态，避免继续混用 emoji。若直接使用 Codicons 资源，须核准精确版本并保留其 [CC BY 4.0 许可证](https://github.com/microsoft/vscode-codicons/blob/main/LICENSE) 及署名信息，不能默认按 MIT 处理；也可先采用原创的统一线性矢量。

## 现有命令的收纳映射

| 现有入口 | 新入口方向 |
| --- | --- |
| 设置、切主题、帮助 | 更多→设置/外观/帮助 |

| 保存、导入副本、导出、重载文件、恢复草稿 | 更多→文件；Ctrl+S 保留 |

| 文件改名、移动、删除 | Explorer 长按/右键菜单；删除确认保持 |
| 结果面板、收键盘、尺寸/最大化/清空输入 | 面板标题/菜单及更多→显示，易用入口保留 |

Ctrl+O 目前是导入副本。首批需明确保留该行为并修正文案，不能将其改成写回原文件而没有新的文件会话契约；真正打开外部项目从 SAF 工作区入口进入。撤销/重做快捷键另做显式契约验证，不因改菜单而宣称已完成。

## 宽度、横屏和平板

后续使用扣除系统栏/IME 后的实际内容宽高，初始以 <600dp、600–839dp、≥840dp 做布局预算起点，再根据剩余代码宽度和高度判断。它们是设计初值，不是按机型或方向决定布局。

窄窗优先代码，Explorer 覆盖或收起；宽且足高时引入 Activity Bar/Explorer；矮窗或 IME 出现不机械三栏。终端默认底部，可配置侧置；侧栏/底部比例独立记忆，临时窗口约束不覆盖用户比例。P1-A 已完成手机外壳；P1-B 再逐步重排横屏/平板分支。
