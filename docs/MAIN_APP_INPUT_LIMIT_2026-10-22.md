# 主程序集成I2：原生输入上限与旧输入连接隔离

2026-10-22，基线 `8306239cc32e4ddb10242536acda95ebe9b5d557`，继续[主程序集成计划](MAIN_APP_INTEGRATION_PLAN_2026-10-21.md)。本批落实主Sora输入的20万字符预算；I2完整操作链、I3精确动画和I4最终验收继续保留。

## 行为与修改

- 主编辑器按现有Workspace上限计算UTF-16长度，最多200000单位。超预算的IME输入、粘贴/剪贴板、替换、辅助功能整段设置、插入/复制等在修改前整次拒绝，显示“本次输入未写入”；保留原正文、选区和可用的撤销记录，不截取一段用户文字后再回滚。
- 边界内的选区替换、删除和中文组合提交仍可使用。组合输入从固定Sora 0.23.7公开InputConnection查询返回的真实Spanned组合区域读取，计算组合与选区的重合部分；不把光标位置推测成组合区，不复制一套IME组合状态机，不读取私有字段。
- 对API33/34新输入重载分别使用版本隔离的包装类；Android9主机模型使用旧接口，Android14模型验证带TextAttribute及replaceText的路径。旧连接、旧Content及关闭后的连接不能继续修改新文件，也不能结束新连接的批次。
- 公共原生插入、批量缩进/减少缩进、复制行/选区、拖放、鼠标Ctrl拖动复制及Ctrl+Alt+Enter也加入预算检查。混合Tab与空格减少缩进可能因规范化而增加字符，按固定组件实际规则预算后仍调用原组件执行。
- 自动括号与自动缩进继续由Sora生成；临近上限、自动扩展无法容纳时保留普通原始输入并省略本次扩展，不改全局设置。包裹选区的内部选择规则未公开，因此采用保守预算，边界处可能退化为普通替换；普通文件里的括号补齐和智能缩进已验证保持。
- 继续使用现有工作台、文件/草稿控制器、设置、补全、真实Python/Wandbox与单一PTY；没有升级Sora、关闭元数据检查、复制编辑器内核或增加实验功能页。
