## 四组工作

1. HTTPS 协议与固定引擎。沿用 Dulwich 1.2.20/urllib3 2.8.0，核对实际版本的 HTTP/pack/refs API和已打包Python的CA行为。只接受明确的 HTTPS 来源，禁止URL内的凭据、隐式外部命令/全局代理/凭据助手、跨来源凭据转发和静默重定向。真实TLS夹具验证认证、pack获取、单分支非强制推送与错误；标准Git只检查隔离的本机测试仓库，不操作用户项目。
2. 工作区事务。克隆写入明确的新目标，非空/并发变更/失败/取消保护原项目；获取只更新对象和远端跟踪引用。快进更新必须核对祖先关系、索引/工作树、未保存与恢复草稿、未跟踪文件冲突和确认的远端版本，不进行隐式合并、重置或强制覆盖。内部目录与SAF都接入真实有界二进制事务，扩展原备份/校验/条件恢复以处理正文创建/修改/删除和远端元数据，不拿旧镜像当真实工作树。
3. 凭据。原生后台使用Android Keystore密钥加密令牌，禁止明文后备和项目内配置凭据，提供清除入口。令牌输入不进入窗口状态、日志、错误详情、Git URL或恢复包；默认临时使用，用户明确选择后才保存在设备。公共读取不要求令牌；认证失败、密钥失效、撤权有明确状态。
4. 实际界面与服务。复用源代码管理侧栏和共享表单/阅读浮层，提供克隆、远端配置、获取、明确的安全快进和推送。操作前显示来源/目标/分支/提交及范围；推送只针对确认的单一提交和引用，不允许force，远端变化须重新获取。区分本地文件失败和远端可能已接受的推送，取消或超时不能假报远端必然未改。网络操作不自动触发，其他未保存编辑、设置草稿和真实运行/PTY保留。
