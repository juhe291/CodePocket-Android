# 命令菜单图标、分组与快捷键排版（2026-10-24）

基于21e49eb继续UI优先范围。原图标主要由标题文字推测，导致“停止程序”“跳转行”等命令落到通用信息图形；编辑菜单缺少分隔，大字体/窄菜单中快捷键会挤占名称位置。

## 改动

- 顶部七类入口使用明确的本地Lucide图形。IdeCommandMenu按现有命令身份指定图标、分组和删除危险状态；停止使用方形、定位使用准星、面板收起使用向下箭头。标题改变不改变命令身份或样式；无需增加图标资源/许可证依赖。
- 编辑菜单按历史、查找定位、字号和代码辅助分组。原命令集合、顺序、启用校验、组合输入保护、异步派发及迟到回调保护保持，没有新运行/保存功能。
- 带快捷键的行在字号比例大于1.3或菜单宽度不足300dp时，名称和快捷键上下排列；正常窗口继续右侧显示。字号入口明确显示现有Ctrl++/Ctrl+-，触屏仍进入原字号对话框。无快捷键行保留原来的直接文字子项结构。
- 排版参数复用，不在onMeasure内新建LayoutParams；未修改编辑器或PTY绘制/输入。旧列表选择器继续兼容标题图标推测，不把它们描述成已全部迁移至命令模型。
- 可点击样稿编辑菜单同步九个已有动作和分组，新增320px菜单下快捷键换行检查。并纠正样稿README中31×4×2误写为29×4×2的文字数字。
