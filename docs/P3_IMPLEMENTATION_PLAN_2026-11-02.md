## P3-A 四组实际工作

1. 固定离线Git引擎。候选Dulwich提供纯PythonGit实现，不要求设备安装git可执行文件；只在独立缓存取得官方固定wheel、完整依赖、摘要和许可，不先改生产依赖。检查纯Python轮是否完整、CPython3.13可用、没有隐式调用git/ssh/编辑器/钩子/过滤器/GPG。用标准Git交叉验证真实对象、索引和打包对象；可行后再选择固定版本并入主APK。候选不合适时保留证据并选其他真实实现。
2. 工作区与服务。Git后台工作独立于分析/格式化/程序/PTY。内部目录不得越界；外部SAF须读取新鲜提供方，不能把旧编辑镜像当真实仓库。暂存/提交针对明确的已保存版本；有未保存缓冲时先经原保存/冲突保护或明确选择，不暗中丢弃草稿。必须验证.git元数据、二进制对象/索引的有界读写与中断恢复；SAF没有统一原子重命名时须有冲突/失败保护，不能只实现内部项目就宣称外部仓库支持完成。
3. 原生源码管理入口。复用树/搜索的手机抽屉和平板侧栏及固定活动栏，增加确有功能的源码管理入口。显示仓库/分支、已暂存/未暂存/未跟踪和真实差异；空项目给实际初始化或打开入口，非仓库不假报干净。长内容保留选择/复制和关闭返回，迟到刷新不得切回旧工作区。
4. 本地写操作。真实暂存/取消暂存、提交身份/消息/已暂存范围和提交历史；使用对象/索引/refs一致性校验，失败不改HEAD或吞掉原文件。仓库配置中的外部命令、钩子和过滤器不自动执行。所有网络操作留P3-B并由用户明确触发，本地Git不自动同步。
