## 已复现与修复

设置选择改变主题时，会先异步保存未保存的代码。原设置页只禁用“应用”按钮，其他表单仍可改动；真实保存等待期间继续点击“显示行号”等选项，会改变草稿，但稍后的成功回调仍按先前提交值关闭窗口，后续选择被静默丢弃。`settings-before-fix3`在实际主Activity、设置弹窗和真实保存路径上复现了这个差异。

现在提交期间锁定设置表单、分类、搜索与操作按钮，显示“正在应用…”，阻止返回取消和迟到表单回调继续改草稿。窗口变宽而重建控件时也继续锁定。保存失败后恢复可编辑状态及按钮，保留原草稿、搜索和错误说明；成功后按已提交值完成应用。原保存冲突、草稿保护与编辑器事务保持。
