## 实际功能

- 源代码管理标题栏的“远端 Git”菜单：HTTPS克隆、配置origin、查询分支、获取、安全快进、单分支非强制推送、凭据、推送记录及恢复导出。打开面板和本地配置读取不自动联网；查询、获取、克隆和推送由用户明确触发。
- 克隆到新的内部独立项目或系统授权的空目录。默认项目保持原样，新内部项目有稳定身份并可从工作区菜单重开，不生成样例正文。克隆失败保留未完成项目和恢复记录供检查。
- 获取只更新对象和远端跟踪引用。快进前显示来源、分支和两端提交；原文件完整备份、活动恢复草稿、编辑变化、原工作区版本和事务日志共同保护正文，拒绝合并、重置、非快进及覆盖未跟踪内容。内部POSIX克隆启用执行位，SAF保留Git索引模式但不伪造提供方chmod能力。
- 推送确认一个本地提交和一个远端分支，校验已获取的远端提交；持久意图先于IPC，服务报告先写回执再回复界面。取消或报告丢失显示结果未知，提示重新获取核对；迟到或关闭界面不会抹除已确认回执。清理入口只删除已确认记录，未知和进行中记录保留。
- 凭据默认仅保留当前应用会话；明确勾选后用AndroidKeyStore密钥/AES-GCM加密，按规范HTTPS仓库绑定，提供单仓库/全部清除。令牌不进入URL、项目、日志或Bundle，输入屏蔽自动填充和视图保存，关闭/销毁同步清空。原设置草稿、编辑器、运行和PTY仍由既有所有者管理。
