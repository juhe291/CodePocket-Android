# P2-B Python 项目语义上下文

2026-10-26。沿用主 App 与 P2-A 的 Jedi 0.20.1 / Parso 0.8.7、独立 `:analysis` 服务和生产 Sora。UI 零碎润色停止，本批只改项目上下文与分析资源边界。

## 本批实现

1. `Workspace.pythonSources()` / `PythonSources`：内部项目重新枚举并严格读取 UTF-8；SAF 直接枚举真实提供方，读取当前 `.py` / `.pyi`。不经过旧节点表或编辑镜像，不调用运行快照，不更新保存版本。新增、删除、改名和提供方替换 ID 都以当前读取为准；拒绝循环、重复名称、路径逃逸和链接。
2. `EditorSessions.analysisKeys()` 在 UI 线程复制会话身份；`DraftStore.analysisTexts()` 按这些身份原子读取有效恢复草稿。当前编辑器正文优先，其余同项目源文件的未写回草稿覆盖已保存内容；排除其他项目、备份条目、路径不符条目和已经删除的文件。沿用原有“切标签先保存”和恢复流程，没有新增一套缓冲区管理器。
3. `PythonProjectContext` 在独立缓存中形成不可变、内容寻址的源码快照。真实后端以它为项目根，能解析多个未保存模块的传递导入、包内相对导入及 stub；原文件、提供方、编辑镜像、恢复草稿均不被分析写入。相同内容复用；不同内容新建，最多保留三版；分析后、发布前再次校验项目、草稿和快照内容，变化时拒绝旧结果。显式重新请求会重读项目。
4. 资源边界：最多 1000 项目录、20 层、128 个源文件、单文件 20 万 UTF-16 单位、总计 100 万单位；当前文档仍限 45000。自动请求先合并 120ms。提供方读取有独立单线程/一个排队位，单次等待最多 5 秒；忽略取消的提供方不会阻塞 UI、保存队列或无限增加线程。原分析服务初始化/热分析 30s/8s 看门狗保持，只处理分析进程。Parso 导入模块磁盘缓存每次分析前后修剪至 16MiB / 256 文件，和三版项目源码快照分别限制。

项目分析失败、撤权、读取超限或上下文发生变化时保留词法/内置参考。显式超大文件请求给出限制说明，不再持续显示“正在分析”。没有新增依赖、网络补全服务或用户代码上传。

## 验证方法与边界

- `PythonProjectContextTest` 验证多个草稿覆盖、原文件保持、缓存复用/不可变/上限、篡改检测、实时提供方增删与 ID 替换、保存冲突基线不变、异常和取消。
- `ProjectReadExecutorTest` 用故意忽略中断的读取证明超时、有限排队与恢复；`AnalysisDiskCacheTest` 证明字节/文件双上限、保留最新项和缓存外源码不受影响。
- `generate_project_semantic_fixtures.py` 用真实固定后端分析三组实际源码快照，检查正确候选、错误类型候选缺席以及真实第二参数。实际 Main/Sora 测试仅替换 Android IPC，要求生产快照的文件正文逐项等于被真实 Jedi 分析的正文；测试真实接受、撤销、SAF 新鲜读取、撤权和迟到结果。
- Python 源码用例还覆盖传递导入、包/相对导入、`.pyi` 与删除/改名后不残留旧模块；APK 验证加载实际打包的依赖与语义字节码重新运行这些用例。
- 原生截图来自 Main/Sora + 主机真实后端结果回放，不是设备服务执行证据。已查看平板多草稿候选、手机跨文件参数和 SAF 新鲜模块候选，文字/活动参数与关闭入口可见。

证据目录：`verification/python-project-context-2026-10-26/`。首次受限 Gradle daemon 连接失败和系统临时目录访问失败保留；首次测试编译中的字段名错误已修正，未删除断言。第一次完整流程被会话中断，停在 Lint 阶段且未生成新 APK；其日志/JUnit另存 `full-interrupted-before-apk.log` / `interrupted-junit`。补齐 Parso 磁盘缓存边界后完成定向与完整流程。本批只有最终流程实际生成一次新 APK。

## 尚未声称通过的部分

真实 SAF 提供方没有跨文件原子读取接口；本实现读取请求时的内容，并在结果发布前重读校验。不能证明提供方之后不会再变化；重新请求会再次读取，不以旧快照作为新结果。单个已卡住且不响应中断的提供方调用可能保留一个共享读取线程，后续请求有界失败，保存/UI 使用其他队列。

主机证据不证明 Android JNI/服务实际启动、真实提供方延迟、设备内存/冷启动或 FPS。设备、IME/键鼠、API24 与卓易通仍按用户要求后置。C++ 语义、本地 C++ 可行性、多文件运行、批量用例、格式化与 P3 原需求继续在计划中；本批不将它们标成完成。
