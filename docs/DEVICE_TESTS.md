# Android 设备验收清单

这些检查需要在 Android 设备/模拟器中实际操作。主机单元测试和 APK 构建不能代替它们。

| 范围 | 操作与通过标准 |
| --- | --- |
| 冷启动 | Android 7+ arm64 设备安装 Debug APK，离线启动，无崩溃，显示示例文件 |
| 主题与生命周期 | 修改代码、stdin，切主题、旋转、分屏、返回桌面再进入；代码、标签、当前文件和设置保留 |
| 多文件 | 嵌套目录中打开 `.cpp/.h/.hpp/.py`，切标签、关闭当前标签；缓冲区不串文件 |
| 保存失败 | 测试设备模拟写入失败；状态显示失败，切换/关闭/运行不丢失缓冲区，不显示保存成功 |
| 文件安全 | 新建、移动、重命名目录，检查已打开子文件标签同步；取消删除不改文件，确认删除后无旧文件复活 |
| 系统文件 | SAF 导入源码，在内部修改；外部原文件不变。导出后检查文本。取消选择器不改项目 |
| 窗口 | 测试 360/600/720/960 dp 窗口宽度与自由窗口拖动；窄窗上下布局、宽窗结果分屏、平板文件树；Ctrl+B 可切换 |
| 输入法 | Gboard/系统输入法输入中文注释、换行、选区替换、粘贴多行；不破坏 composing、光标和原生复制粘贴 |
| 编辑规则 | Python 冒号、C++ 花括号后换行自动缩进；Tab、Shift+Tab、括号/引号补齐、跳过已有闭括号；注释/字符串中的括号不参与匹配 |
| 键盘 | 蓝牙键盘验证 Tab/Shift+Tab/Ctrl+Space/Ctrl+S/N/O/B/F5/Ctrl+Enter；选择多行后缩进，系统拦截项另记 |
| 鼠标 | 定位光标、拖选、滚轮、原生编辑上下文菜单；文件树右键/长按打开管理菜单 |
| Python | 断网执行 stdin 求和、math、工作区模块；修改模块后重跑应生效；traceback 点击打开对应模块行 |
| 超时与限量 | Python `while True: pass` 约 6 秒终止；超长 stdout/stderr 保留错误提示；之后正常代码仍可运行 |
| 运行状态 | 运行期间反复按 F5，旋转/切主题后再次按 F5；只运行一份，结果返回新界面；阻止重命名/删除运行中的文件 |
| Wandbox | 首次运行显示第三方发送提醒；正常 STL/stdin 程序、语法错误、非零退出、断网、HTTP 失败与超时各验证一次 |
| 输出导航 | A 文件运行后切 B，点击错误应返回 A；Python 模块错误打开模块；已删除的错误文件给出提示 |

Python 在应用进程内执行，不是安全沙箱；字节码 watchdog 不能强行打断 `sleep`、阻塞 I/O、原生扩展或恶意关闭 trace 的代码。此限制必须保留在 README 中。
