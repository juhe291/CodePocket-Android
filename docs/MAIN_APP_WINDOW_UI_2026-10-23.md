- 手机360×800、1.6倍字体下创建并打开真实长文件名，最后文件夹和根目录反复收起/展开，子项真实增删且活动文件不关闭。平板1000×800、1.6倍字体下设置左右分栏与结果可见，按钮贴底；API28手机大字体同样通过。
- 正常配置重建保留代码、光标、稳定文件键和用户已关闭的面板；终端快捷按钮反复点击只展开/定位，不重复创建、反向关闭或唤起键盘。
- 真实Runtime失败保留完整私有日志，摘要不直接展示堆栈；详情原生滚动/选字/复制后剪贴板与完整记录一致；准备期重试不递增第二次启动；后台失败不抢代码焦点。
