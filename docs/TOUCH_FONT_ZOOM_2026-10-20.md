# 手机隐藏字号入口

## 使用

代码区底部 **⋮（编辑操作）→代码字号→A− / A+**。窗口显示当前字号，可连续调整；每次1sp，范围10–28sp，立即生效并保存，点击“完成”或返回关闭。与Ctrl加减共用字号，行号同步缩放，终端字号不变。

[下载触屏字号Debug APK](../dist/CodePocket-touch-font-zoom-2026-10-20-debug.apk)，Android7.0+ / arm64-v8a、同旧Debug签名，可覆盖安装。实施批次为2026-10-20；文件名按批次保留。

## 修改

- `ui/IdeCommands.kt`：追加稳定的FONT_SIZE命令，编辑菜单增加一个“代码字号”入口，保持最多7项及原有操作；主界面不常驻放大/缩小按钮。
- `MainActivity.kt`：复用共享原生弹窗和已有zoomEditor，提供当前字号、A−、A+及边界禁用。触屏可在编辑器未获得焦点时调整，保留原输入焦点；键盘缩放仍要求编辑器焦点。工作区忙碌、文件未载入或组合输入时阻止操作。
- `ui/IdeIcons.kt`：复用本地Aa图标，不增加图标资产或改变终端图标。
- `res/values/strings.xml`：字号窗口、无障碍按钮说明及手机路径帮助。
- `CompletionInteractionTest.kt`：新增手机隐藏入口点击与平板输入焦点/组合保护两项完整Activity回归。
- README、交接与P1记录：更新下载和操作说明。

Java/Kotlin主源码相对路径为 `app/src/main/java/com/codepocket/ide/`，测试相对路径为 `app/src/test/java/com/codepocket/ide/`。字号直接保存，不是设置中心的待应用草稿；关闭窗口不回退已经选择的字号。原实体键盘候选导航、快捷键、文件安全、真实Python/C++运行和单一PTY终端保留。
