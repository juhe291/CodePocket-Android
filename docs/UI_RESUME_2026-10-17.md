- 搜索只有模块而无 UI 入口，直接 listFiles 遍历绕过工作区过滤，取消会在任务启动时重置；动画只检查 App 开关，旧动画结束回调可能干扰快速开关。

## 已完成的接续

1. 全局菜单只保留主题/设置/快捷键/帮助，常规宽度4项；窄窗口及面板隐藏时按状态提供必要入口，最多8项。Explorer 标题有新建文件/目录及文件菜单；重命名/删除复用原确认与安全实现。编辑器工具栏直接提供保存/撤销/重做/查找，另有6项短菜单；所有旧21项命令和新命令在实际使用的控件/菜单集合中都有触屏入口，测试不再仅检查 enum 是否存在。
2. 主栏增加项目搜索，标题点击切工作区、长按显示路径；Ctrl+F 保留文件内搜索，Ctrl+Shift+F 项目搜索。符号栏移动到内容区下方、键盘上方，显示时替代编辑器工具栏，包含触屏编辑/符号/补全入口；代码/stdin/组合区和忙碌检查仍在执行时重验。
3. 面板最大化/还原、关闭、清空显示均连接真实逻辑；清空预设输入是单独命令，不混同输出清空。清空显示保留 RunResult、错误位置及 stdin，同一结果重绘不恢复旧显示，新运行/结果恢复显示。尺寸菜单仅处理几何；面板关闭后主菜单可找回。
4. 复用一个响应式侧栏实例，窄窗隐藏侧栏及 Activity Bar，变宽恢复；独立维护侧栏/覆盖窗口文件列表，工作区重建清空旧控件引用。几何使用内容区像素换算后的 dp，扣除主栏/符号栏/状态栏实际占用；拖动从固定起点计算，支持24dp分隔区、方向键调整和点击恢复，用户宽度偏好不被临时窗口约束覆盖。
5. 保留底部优先面板；当净工作区宽≥600dp、高160–359dp且上下分屏放不下时，自动左右分屏，保留编辑区和结果。宽度不足或显式最大化仍按约束处理。状态栏显示逻辑行/UTF-16列、缩进、语言与真实操作消息；新编辑不会继续宣称当前缓冲已保存，保存失败仍可见。
6. 返回键按原生弹窗优先，其后依次收键盘、收侧栏、还原最大化、收面板、退出；有未保存内容时提供保存退出/导出/取消，保存失败留在编辑器。API24 原生返回路径保留，预测性返回尚未设备验收。
7. 接入真实项目搜索对话框与结果定位，任务走 WorkspaceIo 串行后台队列，使用 Workspace.children/resolve/read，遵守文件/SAF 边界。支持大小写、当前未保存缓冲覆盖、最多200行UI结果、1000项/20层/8Mi字符扫描预算、取消和过期/工作区校验，明确提示跳过及达到上限；定位前核对行内容变化。
8. 接入原 ANSI 原型为只读结束后输出显示：8色 SGR、粗体/斜体/下划线、跨块序列及清空重置，输出字符/行数受限。修复未知 CSI 吞后续正文：`ESC[I` 是非支持控制序列，其后的 `nvalid` 应保留；相应旧断言改为准确协议行为，并新增边界回归。不是 VT 屏幕仿真，不支持完整 ANSI、交互式 stdin 或流式后端。
9. 动画取消先移除旧结束回调，复位透明度/平移；侧栏动画遵守现有 App/系统动画缩放/省电/IME 策略，暂停、重建和关闭动画时收敛到明确可见状态。没有实现或宣称平滑光标、60 FPS 或高刷新率通过。
