## 本批行为

- “运行 → 测试用例”是唯一用例入口。按文件稳定会话身份保存名称、标准输入、预期输出和比较规则，支持创建、编辑、删除、单项/全部顺序执行、记录阅读、选择、复制实际输出及错误定位。默认逐字比较，可仅忽略末尾 CR/LF；空格、中间换行仍参与比较。
- 生产队列每项重新准备实际 Python/C++ 项目和有效草稿，执行并原子保存后才进入下一项。用例与源码上下文绑定；编辑源码或准备期间变化时停止剩余项。编译/服务/网络失败中止队列，答案错误、运行错误、超时可继续；Ctrl+C、停止、终端关闭和页面结束都不启动下一项。未执行项不会伪造运行结果，旧记录标明“上次”。
- Python 采用生产 runner 的有限输入；本地 C++ 运行器读取真实有限 stdin 文件，stdout/stderr 独立，不消费外层终端键盘或伪造 EOF。普通交互运行仍使用真实 PTY。本地失败不会自动上传，Wandbox 仍保留原上传同意。
- 原子存储保留历史；删除或编辑用例后仍能查看原快照。每文件最多 20 用例、40 条历史，内容有总量限制；stdout/stderr 记录各有 5 万字符上限并保留截断说明。保存失败保留原文件、编辑输入与实际结果。页面重建恢复名称、空白、比较规则及写入中的稳定 id，不重复新建。
- 本地 C++ 成功进入程序后，显示程序启动到观察到退出的墙钟时间，排除准备、编译、输出收尾、故障定位和主线程投递；等待程序输入属于执行期间。准备/编译阶段失败仍显示相应阶段耗时。
- 云端输入提供可触摸的收起按钮，菜单可展开/收起，收起和重建都保留输入。本地 C++ 隐藏该输入及入口，也不消费遗留云端预填文本。用例的固定输入是各用例自己的数据。
- 外观代码预览按 token 使用正式 Sora TextMate 主题资产，跟随实际语法主题与代码字号。界面浅色、语法固定 Dark+ 时仍显示 Dark+，主题选择维持草稿/应用/取消行为。
