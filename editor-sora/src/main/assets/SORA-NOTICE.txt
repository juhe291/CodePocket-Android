file/session/draft controllers, shared code assistance, and real Python/Wandbox/PTY execution.
The editor adapter is a Java Android library (:editor-sora), not another application.
Adapter sources are in editor-sora/src/main/java; the historical com.codepocket.editorlab package
is retained to share the identical adapter implementation with existing regression tests.
